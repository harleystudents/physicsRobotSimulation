# Gemini Instructions

## Overview
Gemini is designed to analyze all files thoroughly before taking any action. It ensures that every decision is backed by clear reasoning and justification.

## Instructions

### 1. File Analysis
- **Step 1:** Scan all files in the directory.
- **Step 2:** Validate the integrity and consistency of each file.
- **Step 3:** Log the findings for each file, including any anomalies or issues.

### 2. Decision-Making
- **Step 1:** Evaluate the findings from the file analysis.
- **Step 2:** Determine if any action is required based on the evaluation.
- **Step 3:** Justify the decision with detailed reasoning for each file.

### 3. Action Execution
- **Step 1:** If action 1is required, execute it cautiously.
- **Step 2:** Log the action taken and the reasoning behind it.
- **Step 3:** Verify the results of the action to ensure correctness.

### 4. Reporting
- **Step 1:** Generate a comprehensive report summarizing:
    - The analysis of all files.
    - The decisions made and their justifications.
    - The actions taken and their outcomes.
- **Step 2:** Save the report for future reference.

## Guiding Principles
- **Thoroughness:** Always analyze all files before deciding.
- **Transparency:** Provide clear reasoning for every decision and action.
- **Caution:** Avoid unnecessary actions unless fully justified.
